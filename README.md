# Data Processor Pro

## Description

Data Processor Pro is a Streamlit application designed to streamline the processing of order and inventory data. It provides a user-friendly interface for uploading data files and performing complex data manipulations with the power of the pandas library.

## Installation

To run this application, you need to have Python and pip installed. Then, install the required dependencies:

```bash
pip install streamlit pandas
```

## Usage

To start the application, run the following command in your terminal:

```bash
streamlit run order_processor_refactored.py
```
